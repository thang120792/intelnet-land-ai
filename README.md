# 🏡 INTELNET — Trợ Lý Pháp Lý Đất Đai Thông Minh Tỉnh Thanh Hóa

Bot tư vấn pháp lý đất đai sử dụng AI, được xây dựng trên nền tảng:
- **ZenMux API** (GLM-5.3, Dots3, DeepSeek-V4 Flash)
- **Gemini API** (Google AI)
- **Kho tri thức 56,730 mục** từ Luật Đất đai 2024, NĐ 101/2024, QĐ 2604/QĐ-VP Thanh Hóa

## Chức năng
- Tư vấn thủ tục tách thửa, cấp sổ đỏ, sang tên, chuyển mục đích sử dụng đất
- Tra cứu biểu mẫu đất đai chuẩn Thanh Hóa
- Giải đáp pháp lý đất đai dựa trên kho tri thức chuyên sâu
